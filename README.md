# Personal Website

این پروژه یک وب‌سایت شخصی و حرفه‌ای است که برای معرفی مهارت‌ها، تخصص‌ها، پروژه‌ها و فعالیت‌های من طراحی شده است.

## امکانات پروژه

- صفحه اصلی حرفه‌ای
- بخش درباره من
- بخش تخصص و مهارت‌ها
- نمایش پروژه‌ها
- فروشگاه آنلاین
- داشبورد حرفه‌ای
- اپلیکیشن چت
- بخش تماس با من
- طراحی مناسب برای موبایل و کامپیوتر

## تکنولوژی‌های استفاده‌شده

- HTML
- CSS
- Tailwind CSS
- JavaScript

## هدف پروژه

هدف این پروژه ایجاد یک وب‌سایت شخصی مدرن برای معرفی توانایی‌ها، مهارت‌ها و پروژه‌های انجام‌شده است.
